# docs/ — conventions

Note: the root `CLAUDE.md` describes an unrelated project (Colaberry). It does not apply here. This file is the actual convention for this folder.

**Purpose:** written material — weekly write-ups, notes, diagrams; anything that explains rather than executes.

**Belongs here:**
- Markdown or PDF docs, e.g. `week3.md`

**Never goes here:**
- Source code (that goes in `src/`)
- Secrets
- Generated build artifacts

**Status:** scaffolded, currently empty.

**Verification:** markdown renders cleanly; no broken links.
